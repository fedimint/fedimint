pub const LNV1_INCOMING_HTLC_EXPIRY_SAFETY_MARGIN: u16 = 30;
Expand description

Exclusive remaining-CLTV safety margin for funding LNv1 incoming contracts.

Fresh intercepted HTLCs must have more remaining blocks than this margin. The value matches the route-hint delta advertised by pre-upgrade clients so that their invoices remain payable; once the deployed client fleet advertises LNV1_INCOMING_HTLC_ADVERTISED_EXPIRY_DELTA, enforcement can be raised towards it.
