Module peer_availability 

Source
Expand description

Guardians’ views of each other’s availability.

The public PEER_AVAILABILITY_ENDPOINT serves them. Each guardian reports when it last saw each peer take part in consensus and, per window, how much of the window it observed itself (coverage_bps) and the fraction of that time each peer took part. A single report is one guardian’s opinion; clients combine the reports with merge_peer_availability.
