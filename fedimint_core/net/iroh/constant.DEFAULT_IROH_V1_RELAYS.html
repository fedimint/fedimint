Fedimint-operated relays running the Iroh 1.0 relay protocol.

The relay wire protocol changed incompatibly between 0.35 and 1.0, so these are separate deployments from DEFAULT_IROH_RELAYS and the two lists must never be mixed. Kept here next to the 0.35 list so both are maintained in one place; the RelayMode is built by callers that have the iroh_next types in scope.

The iroh.fedimint.org entries are placeholders for a later migration to Fedimint-owned domains and do not resolve yet. Iroh only selects a home relay that answered the current round of probes, which run in parallel, so an unresolvable entry is never selected and costs one DNS lookup per round. Until a working Iroh 1.x relay serves them, these names must stay unresolvable: any server answering /ping with a 2xx status would be selected as a home relay.
