pub const SESSION_BOUNDARY_EXIT_CODE: i32 = 3;
Expand description

Exit code of a fedimintd whose consensus stopped because a shutdown requested through shutdown_after_current_session took effect at a session boundary: its last session completed and it started no later session, so it signed no units of an unfinished session.

The code depends only on why consensus stopped. Tasks that are still running when the task group’s join times out end with the process; none of them can start a session. Every other stop, including a shutdown scheduled for a given session through shutdown, a session timeout, a failed main task, a panic of the main task, or a signal, exits with a different code or by signal.
